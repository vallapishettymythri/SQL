Data Manipulation Language-
DML commands acts on table data.
TABLE= STRUCTURE (COLS) + DATA(ROWS)
        DDL                 DML
All DML Commands are auto commited.
Execute a command to stop auto commit.
SET IMPLICIT_TRANSACTIONS ON 
To save operations execute COMMIT 
TO cancel the operation execute ROLLBACK
